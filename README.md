# Landing Page - Panorama do Mercado Tech

## Acadêmico
João Miguel Zazula Lopes

## Objetivo
Apresentar um resumo das vagas locais e nacionais pesquisadas na disciplina de Fábrica de Software.

## Tecnologias utilizadas
- HTML
- CSS
- Bootstrap

## Principais percepções
Durante a pesquisa, observou-se uma forte demanda por profissionais com sólida base em lógica de programação e conhecimentos em linguagens voltadas ao desenvolvimento backend (como Java e Python) e bancos de dados relacionais (SQL). No cenário local, destacam-se oportunidades que valorizam a atuação presencial ou híbrida em empresas da região, com foco em manutenção e evolução de sistemas. Já no mercado nacional, há maior volume de vagas voltadas ao trabalho remoto, exigindo autonomia, familiaridade com metodologias ágeis, boas práticas de arquitetura de código e conhecimentos em testes de software.
